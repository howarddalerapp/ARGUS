# ARGUS Security Disclosure

This repository contains public-facing project documentation for the ARGUS security modernization project. Detailed infrastructure configuration and sensitive operational data (IP addressing, VLAN maps, firewall rules, device credentials, and detailed camera coordinates) are intentionally omitted from the public site to reduce the risk of information exposure.

If you are an authorized board member or contractor and require access to detailed operational documentation, contact the project owner: howarddalerapp@gmail.com. Requests will be reviewed and access granted via a controlled channel (private share or limited GitHub access).
