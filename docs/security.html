Security Plan — Defense in Depth

High-level policies, retention, access, and legal controls — from ARGUS_Security_Plan.md.

Layers

  1. Physical Security — cameras, gates, lighting
  2. Access Control — fobs, NFC, visitor intercom, least privilege
  3. Network Security — VLANs, firewall rules, no open ports
  4. Data Security — on-prem UNVR, 30-day retention, export policy
  5. Monitoring — AI alerts, weekly log review
  6. Incident Response & Audit — documented escalation path, annual review
  7. Legal & Compliance — privacy notices, Luke Burke sign-off for LPR

Operational checklists

Each phase includes a pre-go-live checklist (passwords changed, VLANs verified, backups saved, privacy notices posted).
