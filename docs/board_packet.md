# ARGUS Board Packet

## Executive Summary

ARGUS proposes a community-wide security camera and access control upgrade for 440 homes. The project improves resident safety, reduces trespass, and supports HOA enforcement. Estimated total project cost: $42,300 (see procurement list).

## Motion for Vote

"Resolved: The HOA approves the ARGUS security project as described in the attached materials and authorizes up to $45,000 for procurement and initial installation, with final vendor selection delegated to the Board President and the ARGUS project lead."

## Key Benefits

- Improved perimeter coverage and incident recording
- Centralized access control for resident fobs
- Evidence collection for incidents and LPR support
