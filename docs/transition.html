Transition Plan — CPS to ARGUS

Phased cutover, parallel operation strategy, and gate cutover checklist — from ARGUS_Transition_Plan.md.

Strategy

Build ARGUS in parallel with CPS, test thoroughly, then cut over one system at a time. Key principle: zero downtime and no resident locked out.

Gate cutover — highlights

  1. Test credentials & LTE stability 48h pre-cutover
  2. Photo current CPS wiring before disconnect
  3. Connect ARGUS UA-Hub to gate dry contact, test four checks (fob, admin remote unlock, loop exit, offline test)
  4. Monitor 48 hours post-cutover
