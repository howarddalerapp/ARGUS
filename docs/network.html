Network Architecture

Logical and physical topology for clubhouse and both gates. See ARGUS_Network_Architecture.md for full diagrams.

Key points

  • Three sites: Clubhouse (WOW fiber), Front Gate (LTE Pro), Rear Gate (LTE Pro)
  • VLAN segmentation: Cameras (VLAN 10), Access (VLAN 20), Management (VLAN 1), Guest (VLAN 30)
  • UNVR stores footage on-premises (30-day retention). Cameras have no outgoing internet access.
  • Access Hubs cache credentials locally — gates work during LTE outages.

IP plan & device map

Static IPs reserved for controller, UNVR, PoE switch; DHCP reservations for cameras and APs. Full table in the source file.
