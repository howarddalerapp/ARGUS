Network Architecture

Logical and physical topology for clubhouse and both gates. See ARGUS_Network_Architecture.md for full diagrams.

Key points

  • Three sites: Clubhouse (WOW fiber), Front Gate (cellular), Rear Gate (cellular).
  • Network is segmented so security systems (cameras, access control) are isolated from guest and resident networks — this minimizes attack surface.
  • UNVR stores footage on-premises (standard retention policy applies). Cameras are restricted from direct outbound access to protect footage integrity.
  • Access Hubs cache credentials locally — gates remain functional during temporary WAN outages.
  • Detailed network diagrams, addressing, and configuration are considered operational-sensitive and are available only to authorized personnel on request.
