Operations Guide

Plain-language how-to for GHS and board members. Source: ARGUS_Operations_Guide.md.

Quick tasks

  • Watch live cameras: unifi.ui.com → Protect
  • Review recorded footage: use timeline or Events tab; export clips immediately if needed
  • Add a resident fob: Access → Users → Add User → Add Credential
  • Deactivate lost fob: Access → Users → Toggle credential off
  • Unlock remotely: Access → Devices → Unlock
