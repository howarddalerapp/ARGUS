# Contributing to ARGUS docs

Thank you for helping maintain ARGUS documentation. This repo is the canonical source for the project. A few quick rules:

- Public docs (in `/docs`) must not contain infrastructure-sensitive details. Use the `SECURITY.md` policy if unsure.
- For small edits to text, open a PR with a short description. For operational changes, open an Issue first and discuss with Howard.
- Use clear commit messages and reference issues where appropriate.
- To request access to sensitive operational docs, open an Issue with the label `access-request` and include your role and justification.
